Requirements:
-----------------------
1. Mysql Database
2. Xampp Server

Setup:
-------------------------
1. Upload the mysql database file.
2. Type in the base url link in the path.php file.
3. replace the mysql database conection details with the conn.php file found in the directory: vehicle_stories/app/database/connection/conn.php
4. Fill in the required credentials for sending of email found in the directory: vehicle_stories/controllers/credential.php
5. Type in the url in your browser.
